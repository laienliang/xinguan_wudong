**原因分析**: 
- Midway 框架可能需要特殊的配置加载机制
- 测试环境的配置文件可能需要额外的配置
- 现有测试文件可能使用了不同的应用创建方式

**建议解决方案**:
1. 检查 Midway 框架测试文档，确认正确的配置方式
2. 参考现有可运行的测试文件 (test/base/, test/user/ 等)
3. 可能需要在测试文件中手动指定配置或使用不同的初始化方式
